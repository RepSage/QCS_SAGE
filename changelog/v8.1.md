# QCS v8.1 — richer DataView for the Doppler current profiler + tunable current QC

> **MINOR** release (v8.0 → v8.1). Adds Visualization controls and exposes the
> current-QC thresholds; **no QC defaults change**, so re-qualifying a file
> with the shipped settings produces the identical flags. (The version bump
> still resets saved QC criteria to defaults on first launch, per the
> version-gated settings rule — the defaults are unchanged.)

## Current QC thresholds are now editable (Settings → Parameters)

The four current tests were hardcoded. `doppler_qc` read a
`CONFIG['dopplerSettings']` that nothing ever wrote, so the Settings window
could not reach them at all. Now a **"Current profiler (Doppler)"** section in
the Parameters tab exposes, with the same Save / Reset-to-defaults / persistence
as every other criterion:

- Max current speed (cm/s) — above → BAD
- Min signal strength (dB) — below → BAD (0 dB and above is the "no ping"
  placeholder, always BAD)
- Max speed stdev (cm/s) — above → SUSPECT
- Tilt suspect / bad (degrees)

`run_doppler_qualification` feeds these to `doppler_qc`, so editing them changes
the current qualification. Defaults are unchanged (300 / −60 / 50 / 15 / 35).

## Doppler Visualization honours the panel controls

Selecting `TSCP Doppler` in the Visualization tab used to ignore every control
but Site and Year. Now:

- **Time window** (X-axis start/end) crops the current data — the field was
  enabled but silently ignored before (a real inconsistency).
- **Depth band** (min/max) keeps only cells in that depth range, and the
  stick-plot / progressive-vector **reference depth follows the band's centre**
  (so "20–40 m" also puts the vectors at ~30 m), instead of always the
  best-covered cell.
- **Fixed scale** ON gives every time×depth heatmap one shared speed colour
  scale (the max GOOD speed over the whole selection), so different sites/years
  compare 1:1; OFF autoscales each panel as before.
- **Cross-site comparison**: with two or more sites selected, a new
  *"Current mean speed across sites"* panel plots mean horizontal speed vs
  depth, one line per site — the current analogue of the scalar
  "parameter across sites" panel.

`plot_doppler_panels` gained an optional `settings` argument for all of the
above; omitting it reproduces the v8.0 behaviour exactly.

## Final polish pass (audit leftovers)

- **Folder mode ("build from folder") auto-corrects the Instrument** the same
  way the file picker does: when the folder holds exactly one instrument's
  `QCS qualified ... data` subfolders, a stale selection is corrected (with a
  log line) instead of failing with "no qualified files found".
- **Doppler panel time axes carry the year** (`%d/%m/%y`): a current database
  can span several years/visits, and day/month alone could not say which.
- X-axis window labels say **"(current)"** in Doppler mode (was "(mooring)").

## Timebase rule made explicit

Every Seaguard deployment records GMT and needs the GMT-3 correction; HOBO
exports and the CO2 logger are already local, and the CO2 file bypasses the
correction even when it is enabled for the Seaguard (it is merged as-is).
Switching the input back to Seaguard now always re-enables the checkbox,
running with it off logs a clear warning (stronger when CO2 is attached, since
the merge would misalign), and the tooltip states the whole rule.

## Batch drivers + corpus index (sourceCode/batch/)

The whole-archive qualification drivers are now in the repo:
`qualify_site.py`, `run_semester.py` (QCS_SG_ONLY=1 restricts to the Seaguard
side) and `build_index.py`, which rebuilds `CLAUDE\qualified_index.csv` — one
row per product with provenance (campaign, cast, inputs, CO2 file, C/D
stations), time span, CO2 points, panel count and path. The README records the
rules the drivers encode (semester naming, timebase, cast clustering,
data-driven replicate grouping, overlap-based CO2 pairing, dedup, idempotent
provenance).

  end: every `DOPPLER_DEFAULTS` key is editable, the defaults agree, and an
  edited criterion really changes `doppler_qc`'s flags — exactly the path that
  was silently dead before v8.1); `ruff` clean.
- Doppler settings reach the QC and change the result (tilt 20° → SUSPECT at the
