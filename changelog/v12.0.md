# QCS v12.0 — The interface moves to Qt

> **MAJOR** release (v11.6.1 → v12.0): the entire interface was ported from
> tkinter to Qt (PySide6 6.8.3, Fusion style). The QC rules and default
> criteria are UNCHANGED — a file qualified by v12.0 with the defaults is
> identical to one qualified by v11.6.1 (proven cell by cell during the
> port). One new opt-in output option (below) can change what the sheet
> CONTAINS when the operator turns it on.

## The new shell

- **Same layout, new toolkit**: the two tabs, the fields and the workflow
  are the ones you know; the window is now Qt with the Fusion style, a
  crisper base font, and **Dark mode** in the View menu.
- The **Execution log is a dockable panel**: drag it, detach it into its
  own window, close it (View > Execution log brings it back). Same
  severity colors.
- **Progress bar** (bottom right): follows the pipeline's own stages
  ('Stage 3/5'), prefixed with the batch/replicate scope
  ('Replicate 2/2 - Stage 3/5').
- **RUN with step-by-step hints**: the button enables only when everything
  required is filled; the hint under it names the next missing step.
  No more pop-up scolding after RUN.
- **Instrument** (renamed from 'Input type') starts at 'Select instrument',
  locks when the file header identifies the family (clearing the selection
  unlocks it), and the Replicates line only exists while there is a HOBO
  selection to count.
- **Selection summary** box: what the readers detected (instrument, files,
  mode, timebase) at a glance before RUN.
- The review windows (light cutoff, replicate review, Depth review, manual
  cut, profile phase picking) are the same matplotlib panels, now opening
  as Qt windows with the app icon.
- Drag-and-drop lands in the ACTIVE tab's file field.
- **File menu**: the file-level actions of the tab (select data file(s)
  `Ctrl+O`, add CO₂ data, select/open the output folder, parameter
  settings, exit `Ctrl+Q`). **Help** carries the user manual,
  **Check for updates** and About.
- **Recent** selections in both tabs: reopen a previous file selection in
  one click (available while no file is selected).
- The **Execution log opens as far as it is dragged**: the tab pages
  scroll instead of blocking the resize, so the log can take the whole
  window when a long run has to be read.
- **Batch status** panel: one row per file of a Seaguard batch with its
  state (running / ok / FAILED), instead of hunting through the log.
- After a run: **Open output folder** and **Go to visualization** buttons.
- The **Selection summary** reads raw `.hobo` headers directly, so the
  logger model, serial(s), launch time and sampling interval are on
  screen before anything is qualified (mismatched intervals are called
  out there too).

## Data visualization

- **Plot colors per parameter**: the color square beside each parameter in
  Scale settings opens the picker (hex codes accepted), and the choice is
  saved and used by every plot. The picker carries **Reset this color**
  and **Reset all colors** for the program defaults.
- **Show disagreement bars** (HOBO only): the vertical bar per sample that
  shows how far the replicates disagreed (bar = max - min, centered on the
  plotted mean) can now be turned off. It starts ON, which is what the
  program did before the option existed.
- Display options in reading order: Fixed scale, Show data points, Show
  disagreement bars, then Tendency lines with its regression degree.

## Knowing which criteria are in force

- The status bar shows **criteria: defaults** or **criteria: CUSTOM**.
- In the Settings window every field that differs from the software
  default is **bold**, and each row has a **↺** button that restores just
  that parameter.
- A **Find** box filters the (long) Parameters list by name.

## New in the output

- **Remove dismissed data** (Data filtering; Seaguard only):
  drops the rows where EVERY variable was dismissed — the Depth review's
  whole-row cuts — leaving a gap in the original Sample numbers. Dismissed
  VALUES were always blanked; this removes the empty carcass rows too.
  Grayed for HOBO (no Depth column, so whole-row dismissals cannot exist).
- The combined replicates' `Temperature series.svg` now draws the
  **replicate-disagreement bars** (bar = max − min, centered on the mean),
  the same visual as the Data visualization HOBO panel.

## Fixed

- The `Remove bad/suspect data` tooltips claimed rows were dropped; the
  implementation blanks the flagged VALUES and keeps every row and
  timestamp. The tooltips now say so.

## Under the hood (why results cannot drift)

The pipeline itself was NOT rewritten. Phase 0 of the port made it
toolkit-neutral (a small UI facade; the same `vals` dict feeds both
shells), and every phase was proven by qualifying the same real
deployments through the old and the new interface and diffing the
outputs cell by cell. The tk implementation still ships inside the
program as the pipeline host (hidden, never shown); removing it is a
future cleanup, not part of this release.

## Verification

- tk-vs-Qt equality: the PLES 2-replicate `.hobo` deployment and the
  BURACAS cast produce identical sheets through either shell.
- Settings dialog: an edited criterion reaches CONFIG, the settings store

- Visualization: database built from a folder join through the Qt tab,
