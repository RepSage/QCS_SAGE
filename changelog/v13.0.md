# QCS v13.0 - the current profiler gets its manual review

> **MAJOR** release (v12.3 -> v13.0). Qualified CURRENT values change: the
> current flag string carries a fifth position (the operator's manual review),
> and a manual dismissal writes flag 5 over the whole row and blanks its
> measurements. Scalar Seaguard qualification now adds three PAR tests and a
> `Flag_PAR` rollup; products from earlier majors must be requalified before
> comparison. No HOBO QC threshold changed. HOBO replicate inputs also fail closed when one
> timestamp carries conflicting readings, instead of silently keeping the first.

## Quality control settings

- **Every settings tab now follows the same instrument order:** Seaguard,
  Seaguard current profiler (Doppler), then HOBO. Each instrument is contained
  in a clearly named box instead of mixing controls by generic test family.
- **HOBO temperature QC is independent from Seaguard.** Sensor range,
  environmental range, spike, rate-of-change and flat-line switches no longer
  reuse the Seaguard checkboxes. HOBO also has its own sensor limits,
  flat-line counts and statistical thresholds. The environmental temperature
  limits remain shared because they describe the site rather than the logger.
- **The four automatic Doppler tests can be switched independently:** current
  speed range, signal quality, speed standard deviation and instrument tilt.
  A disabled test keeps its fixed flag position as DISMISSED (5). Manual point
  review remains a per-run decision, not an automatic-test checkbox.
- **Parameters are organized by meaning.** Seaguard sensor/profile settings,
  Doppler physical limits and HOBO temperature/deployment settings come first;
  HOBO *Light plots* and *Light fouling* are separate, and shared environmental
  ranges come last. The ambiguous *Other parameters* section was removed.
- **Factors per variable is now Statistical thresholds.** Spike,
  rate-of-change and vertical-gradient settings have independent rows and show
  only fields the algorithm consumes. HOBO has separate temperature rows, and
  a row becomes disabled while its corresponding test is off. Doppler explains
  that its direct physical thresholds live in Parameters.
- **Pressure flat line remains OFF by default.** The current criterion counts
  effectively identical samples, not elapsed time, and a fixed pressure sensor
  can legitimately repeat quantized values. Turning it on by default is
  deferred until a duration-based rule is validated against the corpus.
- **The HOBO fixed light-plot ceiling is now 200,000 lux**, covering every
  finite qualified light value in the current archive (maximum 198,401.3 lux)
  while using the plot height more effectively than the UA-002's published
  320,000-lux measurement range. This is a
  plot limit only, never a QC threshold; the automatic-scale companion plot
  still shows detail. Qualification writes both products, while Data
  Visualization begins in automatic scale unless a saved Fixed-scale choice is
  active. *Sustained decline* was renamed *Minimum final run below
  threshold*, and its tooltip now says that the default three days only
  confirms the final non-recovering 50%-of-baseline crossing.
- **Settings labels use O₂ and CO₂ chemical notation.** Default-value emphasis
  now compares numeric values rather than their spelling (`3` equals `3.0`),
  tooltips no longer repeat an `[edited]` suffix, and a single bold header hint
  says that bold means different from defaults. The actionless Doppler
  manual-review note was removed from the test box.
- **PAR is qualified like the other Seaguard optical sensors.** Its sensor
  range is 0-5,000 µmol/m²/s (outside -> BAD), its expected environmental
  range is 0-4,000 (outside -> SUSPECT), and its configurable robust spike test
  can emit BAD or SUSPECT. The three positions roll up to `Flag_PAR`, manual
  point review can dismiss PAR, and the removal options act on that channel
  independently. Negative dark-offset noise is still clamped to valid zero
  before the tests. The spike residual uses the same three-point method and
  factors as the other sensors, but its robust scale excludes valid night zeros;
  otherwise a zero-heavy night collapses MAD and rejects a smooth daylight
  curve in bulk. The archived templates identify PAR-SER ICSW #1372 and
  Satlantic PAR #2301 with the same 0-5,000 hardware range; among 158,815 finite
  archived PAR values, 311 (0.20%) exceed 4,000 and none exceeds 5,000. A
  read-only replay rolls them up as 156,293 good, 1,099 suspect, 1,423 bad and
  19,142 missing, without overwriting an archived product.
- **Pre-v13 JSON settings remain readable.** A legacy shared temperature
  switch/factor seeds both new instrument-specific controls on import; native
  v13 values always take precedence. Preview light-plot defaults of 20,000 or
  320,000 lux migrate to 200,000 without treating that plot scale as QC.

## Data qualification

- **A DCPS session can now be reviewed by hand.** The current pipeline
  returned before any interactive stop, so a current-profiler session was the
  only product nobody could correct: everything the automatic tests missed
  stayed in the sheet. It now stops twice, between reading the session and
  running the tests.
- **The tilt review always runs, one point per record.** Tilt is the DCPS's
  equivalent of the Depth review: it is a record-level series, so cutting a
  point dismisses the whole record - every depth cell of that instant - which
  is how deployment and recovery leave a mooring record. The cut cannot be
  made on depth: in a current table `Depth (m)` is the CELL depth, a handful
  of fixed values repeated on every record.
- **"Check variables" offers the variables a current table actually has**:
  horizontal speed, direction, vertical speed, speed stdev and signal
  strength. It used to offer the nine scalar variables, none of which exists
  in a current sheet, so the chooser came up empty. Each series is shown one
  depth cell at a time, in sequence, instead of the comb the record-major row
  order draws; the tilt cuts carry over locked, so they are not offered twice.
- **A manual dismissal condemns the whole cell sample.** Speed, direction and
  the U/V/W components of a cell are one velocity solution per ping ensemble,
  with the stdev and the signal strength as its own diagnostics: a point the
  operator cannot trust is not one bad column. Every flag position of the row
  becomes 5 and every measurement is blanked, while the row keeps its
  Datetime, Site, Column, Cell and Depth so the cut stays traceable. A cut
  RECORD also loses its attitude context; a cut CELL keeps it, because the
  record is still sound for its other cells.
- **The current flag string has five positions.** The fifth is the manual
  review: 2 when no review ran, 1 when it ran and kept the row, 5 when the
  operator dismissed it. The flag legend written beside the sheet lists it and
  explains the dismissal rule. A current table qualified by an earlier version
  carries four characters and must be requalified to gain the position.
- **The tilt review says what the instrument was doing.** The panel draws the
  two QC thresholds (suspect and bad, as currently set) and shades every span
  where the tilt is 45 degrees or more - lying over, being handled, hauled up
  or on deck - the way the Depth review shades the transits of a scalar
  mooring. On the reference session that band covers the deployment and the
  whole last third of the record, where the instrument went over at 80 degrees
  and stayed there. 45 degrees is the midpoint of a plateau: 299 records
  exceed 35 degrees, 299 exceed 45 and 298 exceed 60, so any threshold in that
  range selects the same events, and past 45 the instrument is closer to
  horizontal than to upright.
- **"Remove dismissed data" applies to a current sheet too**: every dismissal
  there is a whole-row one, so the dismissed rows leave the output when the
  option is ticked, exactly as the Depth review's cuts do for a scalar file.

## Data qualification (both instruments)

- **A Seaguard session says whether it is a mooring or a cast**, and the Data
  type is set from it when the file is chosen: a cast is lowered and recovered
  in minutes and logged fast, a mooring is left down for hours to weeks and
  logged slowly. Measured over the whole archive - 182 labelled scalar
  sessions, 2019 to 2026 - "four hours long OR five minutes between records"
  names 181 of them right; its only miss is a 16-record session that logs every
  10 minutes inside a cast folder. It is a SUGGESTION and never a lock: the
  type decides which tests run, so the box stays editable, the log says what was
  detected and why, and the Selection summary carries the session's length. A
  session too short to time says so instead of guessing.
- **The pipeline checks the Data type against the session it just read**, in
  every shell and in the batch drivers, and warns when the two disagree -
  naming the duration, the cadence and what the tests will do about it. The
  choice is honoured either way.
- **The manual point-cut panels use the program's native buttons.** In the Qt
  shell their Undo / Reset / Skip / Help / Done / Cancel row is made from the
  same native controls, font, palette and interaction states as the panel
  browser's *< Previous* / *Next >* row. The legacy Tk shell keeps a styled
  Matplotlib fallback.
- **A completed manual selection leaves a clean plot.** The drag rectangle now
  disappears on mouse release, after its points have been marked, so it cannot
  cover the next box. Undo and Reset still operate on the dismissed points.
- **Manual-cut Help uses the shell's own dialog.** The Qt button now opens a
  native `QMessageBox` owned by the plot window; the standalone Tk fallback
  keeps its Tk dialog. The callback no longer mixes GUI toolkits or hides a
  failed dialog behind a blanket exception.

## HOBO replicate qualification

- **Duplicate timestamps are no longer resolved by silently keeping the first
  reading.** An exactly repeated signal row is safely condensed with an
  explicit warning. If the same timestamp carries conflicting temperature,
  light or flag values, the referee refuses to name a replicate and the
  combiner stops without writing a combined product, naming the first conflict
  and the possible collapsed 12-hour clock. Existing archived products were
  inspected read-only and were not changed.

## Plots

- **The current panels use the program's standard datetime format.** Their
  time ticks now read `dd/mm/yy HH:MM`, like the scalar panels. The labels stay
  rotated 45 degrees and anchored under their ticks, and the locator is capped
  at nine labels, so the three-day session remains readable without splitting
  the date into a separate offset line.
- **The direction colour key is a compass wheel.** A linear 0-360 bar puts
  north at both ends and never says which colour is east; on the wheel the
  colour IS the bearing, labelled N/E/S/W. Its label is lettered like the speed
  panel's own colour bar - same font, same size, read from the figure rather
  than hand-picked - and clears the N mark by a margin that follows the font.
  The wheel is centred vertically on the direction heatmap and stays wholly in
  its key column. The heatmap it describes is unchanged.
- **The shared plot toolbar keeps only meaningful navigation history.** Home,
  Pan, rectangular Zoom, Subplots, Customize, Save and the coordinate readout
  remain; Back/Forward are removed because they did not record wheel zoom or
  middle-button pan. Coordinates are bold. The manual-cut Reset remains a
  separate control for restoring dismissed points. The retained commands use
  one palette-aware Fluent Regular icon family with consistent 20-pixel sizing
  and spacing; Pan uses a four-arrow move symbol rather than a hand. The
  Subplots, Customize selector and Figure options windows carry their command
  icon. Selecting any non-navigation command leaves an active Pan/Zoom mode,
  so the previously selected lens or arrows do not remain checked.
- **Navigation is bounded and the paired profile stays paired.** Horizontal
  and vertical Pan/Zoom now remain synchronized between the speed and direction
  heatmaps in Current profile. Toolbar and wheel Zoom are bounded per axis from
  1/10,000 to 1x the published opening span, preventing indefinitely small or
  large views without imposing one fixed physical limit on unlike products.
- **Subplots and Customize now speak in plot terms.** The layout editor names
  plot edges and horizontal/vertical gaps, disables a gap that cannot affect
  the current grid, and can offset one or all legends and side keys. Horizontal
  gap is again strictly the space between subplot columns; Current profile has
  one column, so its control is disabled and its scale/compass move only through
  Legend / key position. Both side keys remain aligned with their heatmap when
  plot borders, height or Tight layout move.
  Its exported values open as an owned foreground tool with a Copy all action.
  One global Reset restores plot and legend/key positions; the compact action
  grid places Tight layout over Export values and Reset values over OK. Each
  editable layout row also has the same circular-arrow action used in Settings,
  restoring only that value.
  Doppler Customize choices name the speed heatmap, direction heatmap, U/V
  components and vector plot instead of showing anonymous axes plus
  memory-address IDs, and its title includes the selected plot name. Figure
  options replaces raw datetime X-axis limits with editable Start/End text in
  `DD/MM/YYYY HH:MM`, matching Visualization step 2. Both surfaces reject an
  impossible, reversed or out-of-available-range interval with the same error;
  the live Available range follows the selected Sites/Years,
  renames *Images, etc.* to *Graphs*, removes the ineffective automatic-legend
  control and mappable metadata label, and adds a *Legends* tab for the visible
  line, color-scale and compass labels. Its *Reset values* now refills the
  original fields without applying or reopening; the operator confirms through
  Apply. Each editable Figure-options row also restores independently to the
  original product value and still waits for Apply. Figure options exposes Back,
  Reset values, Apply and OK, in that order;
  Back reopens plot selection and is disabled if no alternative plot exists.
  A *Figure title* field edits the title above the complete product separately
  from the selected plot title. The Graphs selector is hidden for a single
  mappable and retained only when it has multiple real choices. The layout
  editor's Reset uses the same wording.
- **Interactive controls no longer rename Current profile.** Installing wheel
  zoom used to run after the panel received its name and replace that name with
  the compass's internal *Direction [deg]* title. Existing panel names are now
  preserved.

## Data visualization

- **The current panels open in one window, paged.** *< Previous* and *Next >*
  walk through them at the operator's pace, each page keeping its own
  navigation toolbar, and the title says which panel of how many. They used to
  open as one window per figure - one per panel and site, plus the cross-site
  comparison. The scalar and HOBO panels still open side by side, which is how
  they are meant to be compared.
- **A Doppler database no longer shows settings it cannot use, in either
  shell.** The three
  panel checkboxes (still carrying the Seaguard labels), the parameter filter,
  the whole Scale settings column, "Show data points", "Tendency lines" and
  the regression degree are gone for this instrument: the three current panels
  have predefined content and visual treatment, so those scalar controls do
  not apply. Sites, years, the time window and the depth band all still apply.
- **The normal Doppler set is three panels, in a more useful order.** The complete
  time-by-depth heatmaps remain first and the U/V components move to second.
  The one-depth stick plot is replaced by a time-by-depth vector field using
  up to four depths spread through the valid band, matching the U/V panel; a
  drawing-only temporal sample keeps the arrows readable. The progressive
  vector diagram was removed. Regenerating in an existing output folder also
  removes the two retired SVGs, so stale files cannot masquerade as new panels.
- **U/V gaps are an explicit visualization choice.** *Break lines at data
  gaps* leaves a discontinuity wherever that depth/timestamp has no usable
  current; *Connect across data gaps* joins the surviving points; *Generate
  both for comparison* adds the two separately named U/V pages and SVGs to the
  same run. The broken treatment is the default, but neither changes data or QC.
- **Doppler depth availability means plottable depth.** The label and default
  band now exclude cells that are always BAD or blank instead of advertising
  the raw 1-29 m extent. A band containing only one valid cell depth now draws
  a real heatmap row; Matplotlib previously gave that one row zero height and
  showed an empty panel even though values existed.
- **Depth availability follows the live selection.** Changing Site or Year now
  recomputes the range from exactly that subset; selecting none says that no
  data is selected instead of falling back to the whole database.
- **The panel browser has direct navigation.** Its new *Go to* list names the
  site and panel (including the two U/V treatments), while Previous/Next and
  the numeric counter remain available.
- **Slow visualization actions show that the program is working.** *Next >*,
  *Generate panels* and paged-panel navigation use the native wait cursor while
  their synchronous work and final repaint run. The cursor is restored even on
  failure and is local to that window, so validation dialogs still look active.
- **Mouse-wheel zoom works on every current panel.** The Doppler figures now
  install the same cursor-centred wheel zoom and middle-button pan used by the
  scalar panels; scrolling over a colour key or the compass does nothing.
- **Instrument becomes read-only when the qualified files prove it.** Step 1
  inspects every selected header and locks Seaguard, HOBO or Doppler only when
  they agree. Unknown, unreadable or mixed selections remain editable instead
  of inheriting the scalar detector's backwards-compatible default.
- **The post-run shortcuts go away when the selection changes.** "Open output
  folder" and "Go to visualization" point at the run that just finished, so
  they disappear the moment another file is chosen or the field is cleared -
  they used to stay, pointing at the previous run's folder.
- **"Fixed scale" says which scale it means.** On a current database it reads
  *Fixed scale (one speed colour scale)* and explains that the scale is
  computed from the data - nothing is typed. On the scalar families it stays
  the Min/Max the operator types per parameter, and the tooltip now says so.

## Note

- **The blank cells in the reference current panel come from the instrument's
  quality word, not absent raw records.** On the uncut reference session 8,636
  of 13,408 cell samples are BAD, and every one was condemned by the DCPS's own
  cell state - of the 4,772 cells it calls good, QCS rejects none. The pattern
  is geometry: the three cells nearest the transducer (1, 2.5 and 3 m) and the
  farthest one (29 m) are 100% rejected, the middle of the water column between
  40 and 60%, and the last day of the deployment - the instrument lying at 80
  degrees - is rejected whole. A whole vertical gap can instead be a dismissed
  record removed from the output; the qualified table and its flag legend
  distinguish the two cases.

## Verification

- Self-test suite 63/63, ruff clean. A read-only PAR replay used the production
  tests on all 123 archived products (177,957 rows): 156,293 GOOD, 1,099
  SUSPECT, 1,423 BAD and 19,142 missing, with no read error. The 0-5,000 sensor
  limit rejected none and the 0-4,000 environmental limit marked 311 SUSPECT.
  A 625-row real profile and 91-row real mooring were also qualified end to end
  from raw sensor groups; both wrote `Flag_PAR`, kept no negative PAR and passed
  the harness invariants. No archive product was overwritten. The whole current pipeline was run
  end to end on a real DCPS session (13,408 cell samples, 838 records x 16
  cells) three times: with no cut, with a tilt cut plus per-cell cuts, and
  with the same cuts under "Remove dismissed data". Without a cut it
  reproduces v12.3 exactly - 4,646 good, 126 suspect, 8,636 bad; with the
  cuts, 95 rows became flag 5 (`55555`, all measurements blank) and left the
  sheet when the option was on. The visualization changes were measured by
  driving the real Qt shell off-screen over a qualified current table and a
  qualified scalar table, checking that the scalar page keeps its three panel
  boxes, its twelve parameters and its scale column. The mooring/cast detection
  was measured on 182 labelled archive sessions and then driven through the
  real shell on four of them (a 97 h mooring, a 3 h mooring, a 50 min cast and
  a one-record session), and through the pipeline on a real mooring qualified
  both correctly and, on purpose, as a profile. The owner's qualified
  current table then rendered the three panels: each temporal panel
  carried `dd/mm/yy HH:MM` ticks with no offset label. An off-screen Qt
  probe confirmed six native manual-cut controls with the same 10.5 pt font,
  style and stylesheet as Previous / Next, and exercised Done and Skip through
  the window's real event loop. The then-current 8,144-row product was rendered
  at 1-5 m to verify its one valid depth, the compass alignment and the 5-27 m
  available-depth label; two consecutive selector gestures cleared their
  rectangles after dismissing the intended points. The final heatmap treatment
  was compared on the later 8,544-row product: at 4-18 m, 2,524 usable cells
  occupied 491 of 534 timestamps, and the owner chose to omit the 43 instants
  with no usable cell in that selected band. A native Qt Help probe
  confirmed that its dialog is parented to the manual-cut `PlotWindow`, and a
  hidden Tk probe confirmed that Doppler omits the inert panel, parameter and
  scale controls there too. A read-only scan of all 137 archived HOBO products
  found duplicate datetimes in eight (seven repeat roughly half the record; one
  has a single collision), which is why the former silent `keep='first'` path
  was replaced by the explicit duplicate gate. A combined Qt/Tk probe exercised
  all three U/V choices, live Site/Year depth updates and direct panel jumps.
  On the real 8,144-row Doppler product, *Generate both* produced four pages:
  broken U carried 570 explicit gaps, while connected U carried none. A final
  Qt/Tk probe confirmed that proven Doppler input locks Instrument, manual path
  editing unlocks it, and wheel zoom survives attachment to the paged Qt canvas.
  A separate Qt toolbar probe confirmed the six retained actions, absent
  Back/Forward, bold coordinates, palette-aware Fluent icons, matching dialog
  icons, exclusive Zoom state, bounded editable datetime-X text, Graphs/Legends naming,
  form-only reset followed by Apply, removal of automatic regeneration,
  editable color-scale and U/V line-legend labels, a +0.050 figure-width legend
  move, key alignment after border and Tight layout changes, and a visible owned
  Export values tool. It also exercised Back from Figure options to the
  multi-plot selector and its disabled one-plot state, the plot-specific window
  title, shared invalid-range message, and both finite Zoom directions.
  The latest pass also exercised the individual layout and Figure-options reset
  arrows: each restored only its own field, and Figure options left the artist
  unchanged until Apply. The settings probe confirmed the bold default-value
  key and the separate Light plots / Light fouling sections. The release bundle
  was then rebuilt from a clean PyInstaller analysis; its frozen main window
  opened, reached a native window handle, wrote no crash log and closed normally.
