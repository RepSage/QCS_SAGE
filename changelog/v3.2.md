# QCS v3.2 — Atmospheric precision and a depth axis on the profile plots

> **MINOR** release (v3.1.1 → v3.2). Note: item 1 slightly changes the computed
> depths (~0.13 m), documented below.

## 1. Atmospheric-pressure precision
- The pressure→depth conversion was subtracting **10 dbar** (100 kPa) of atmosphere, a
  rounded value. It now subtracts the real **101.325 kPa (10.1325 dbar)**, the standard
  atmosphere.
- Effect: depths computed from pressure come out ~**0.13 m** more correct (deeper) than
  in v3.1.1. A small change, but it does affect results — hence the note.
- Anyone building test spreadsheets by converting depth→pressure must add the real
  atmosphere (**+101.325 kPa**) so that the qualified depth matches the original.

## 2. Fixed depth axis on the profile plots (visualization)
- In the visualization tool (QCS_DatabaseView), new **"Depth-Axis Min / Max (profile)"**
  fields fix the depth axis of the profile plots (panel 3), standardizing the scale
  across profiles — the analogue of the time window on the mooring plots.
- A **"Depth available"** label shows the depth range present in the loaded database
  (like the available-dates label).
- The fields are **greyed out when the type is mooring** (and the time fields when it is
  profile).
- Values are persisted in the user preferences.

## 3. Criteria follow the version (per-version preferences)
- **Important fix:** until now the saved preferences (`qcs_user_settings.json`) stored the
  QC criteria and **restored them on startup**, overwriting the code defaults. The result
  was that criteria improvements in new versions were **masked** by the old saved values
  (e.g. maximum turbidity stayed at 22 instead of 50).
- The preferences now store the **version** (`qcs_version`). On startup, if the saved
  version differs from the current one the program **keeps the version's default
  criteria** (instead of the saved ones), while preserving the conveniences (folders,
  last file, visualization choices). Each update therefore actually applies its new
  criteria. Custom tuning still persists **within the same version**.

## 4. Criterion adjustment
- The **temperature** environmental range goes from 8–32 to **8–35 °C**.

## 5. Density inversion is flagged SUSPECT
- The density-inversion test now flags rows as **suspect (flag 3)** instead of **bad
  (flag 4)**. An inversion signals a **suspect** T/S pair (it is not known whether T or S
  is at fault), so it is not discarded by force: it leaves the result only if "Remove
  Suspect Data" is on. It still implicates both temperature and salinity.
