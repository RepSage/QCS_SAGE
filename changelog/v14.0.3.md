# v14.0.3 - startup visibility and per-database depth limits

Startup and visualization-import fixes; QC rules unchanged
(PATCH: v14.0.2 -> v14.0.3).

## Fixed

- **Show the main window before the upgrade notice.** The blocking
  quality-criteria reset dialog now has a visible parent. Previously the main
  window remained hidden until acknowledgement, making an installer launch
  appear absent. Normal startup and windowless `--shot` keep their behavior.
- **Default depth bounds per imported database or collection.** A Profile
  spanning 0.5-11.5 m no longer inherits 0-30 m from the previous Doppler view.
  Step 2 ignores old global bounds and clears the prior depth-mode cache.
  Manual limits remain within the current view, including filter refresh and
  mode toggles. Shared tooltips and the manual document the import boundary.

## Note

Official qualification, thresholds, measurement fields and timebase rules are
unchanged. Installer launch flags are unchanged. The operator's v14.0.2 log
records installation success at 16:21:42 and an Original user Exec at 16:21:44
on 2026-09-09; the exact historical delay/visibility sequence remains unknown.
The reproduced hidden parent does not prove the sole cause of duplicate starts.

No corpus replay or archived-SVG regeneration was needed for these interface
state changes. Experimental current QC calibration and legacy HOBO event-layout
investigation remain open in STATUS.md.
