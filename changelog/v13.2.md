# QCS v13.2 - curated database and field mode

> **MINOR** release (v13.1 -> v13.2). Quality-control tests, thresholds, flag
> layouts and qualified-value rules are unchanged. This release adds a
> traceable qualified-corpus workflow, makes its output flow directly into
> visualization and gives field computers an explicit way to keep corpus work
> unavailable.

## Fixed

- **Mixed whole and fractional ISO timestamps are parsed without losing valid
  rows.** Database assembly now parses each value with the mixed ISO format;
  the real RODORASO/2019 selection retains all 4,040 rows from its seven
  products.
- **HOBO fouling spans stop at source-product boundaries.** A BAD interval in
  one deployment no longer shades clean measurements from later deployments.
- **Multi-site time alignment is scientifically explicit.** The absolute time
  window is applied first, then independent site series are aligned by elapsed
  days, so sites no longer require matching timestamps. Changing the year
  filter fits the time window to the newly available interval.
- **Workflow locks remain reciprocal and race-free.** Catalog/build activity
  locks Qualification and Visualization, qualification locks both data tabs,
  and controls recover deterministically when a worker finishes or is
  canceled.

## New

- **Curated Database builds a traceable workbook from the qualified corpus.**
  Its row-level catalog filters compatible Site, Datetime calendar year and
  instrument combinations, then writes separate Seaguard, Doppler and HOBO
  sheets plus `Included products` provenance and a `Read me` sheet. It never
  reruns QC or writes into the corpus.
- **Large and interruptible exports are handled safely.** Catalog and workbook
  jobs expose cooperative Cancel, write through a temporary file and cannot
  replace an existing workbook with partial output. Selections representing at
  least 250,000 source rows require explicit confirmation.
- **A completed curated workbook opens directly in Data Visualization.** The
  selected instrument sheet lands on Step 2 without replacing original source
  provenance; multi-instrument workbooks first ask which sheet to use.
- **View > Field mode disables Curated Database.** The checkable choice is
  remembered across sessions, survives other workflow locks and exposes
  explanatory tooltips on both the menu action and disabled tab. Qualification
  and Visualization remain available.
- **Corpus maintenance is explicit and recoverable.** Batch tools now use the
  current `DATABASE` root and include verified procedures for semester-first
  raw organization, monitoring-corpus exclusions and `_SEM_SITIO` resolution.

## Note

- **QC semantics are unchanged.** No test, threshold, flag position or
  qualified-value rule changed in this release.
- **Curated catalog exclusions are defensive.** `_EXPERIMENTOS`, `_PISCINAS`
  and direct `PISCINA_*` site folders remain outside the monitoring corpus even
  if a directory is restored later.
- **The installer does not rewrite archived data.** The separately audited
  corpus operation reassigned the identifiable 2021S2 `_SEM_SITIO` session to
  BURACA_FUNDA and moved the six unknown-origin semester directories to a
  recoverable `_deleted` lane. The current direct catalog and index agree on
  282 products, 644,411 source rows and 34 sites.

## Verification

- **The full QCS self-test suite passed 66/66.** Full-tree ruff, compileall and
  `git diff --check` were clean. The current index and direct catalog both
  report 282 products, 644,411 source rows, 34 sites and zero invalid
  timestamps.
- **Off-screen Qt probes covered the complete Field mode state cycle.** They
  exercised menu and tab tooltips, direct and programmatic navigation,
  persistence before and after the real tab is attached, and both busy-lock
  recovery paths. Existing curated probes cover filters, cancellation,
  visualization handoff and atomic export.
- **A clean PyInstaller build produced a 301,417,581-byte onedir bundle.** Its
  frozen main window rendered to a screenshot, returned exit code 0 and wrote
  no crash log. Inno Setup 6.7.3 produced `QCS_Setup_v13.2.exe` (81,728,586
  bytes; SHA-256
  `FD44A06332306FBCAD4277579EB85AA4C61CCD18BD4A3536F4873A5F1312D1B2`).

## Install

Download and run **QCS_Setup_v13.2.exe**. Installing over an existing copy
upgrades it in place; installed copies of v11.2+ will offer this update on
startup. The default remains the existing all-users location under Program
Files (x86), with the per-user option available in the wizard.
