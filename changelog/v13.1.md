# QCS v13.1 - visualization customization and interface consistency

> **MINOR** release (v13.0 -> v13.1). Quality-control tests, thresholds, flag
> layouts and qualified-value rules are unchanged. This round makes detected
> file identity deterministic, brings visualization controls into one coherent
> order and makes plot customization preserve the product the operator is
> actually viewing.

## Input identity and layout

- **A conclusively detected scalar Seaguard type is now locked.** Clearing and
  dropping the same file again no longer returns an editable Data type. A
  session lasting at least four hours is a Mooring, while a short session with
  a cadence faster than five minutes is a Profile. Short/slow sessions remain
  explicitly ambiguous and editable because the labelled archive contains
  both a mooring and a cast with that pattern. The calibrated rule gives 180
  conclusive results among 182 labelled sessions, with no known false verdict.
- **Input and Output settings keep a stable equal-width split.** Optional rows
  can appear or disappear with the selected instrument without changing the
  cards' horizontal widths in Qualification or Data Visualization.
- **Editable text and path fields have a trailing Clear action.** The native
  icon uses a pointing-hand cursor, fades in and out with the field contents
  and emits the same edit signal as typing. Masked date/time fields and spin
  boxes deliberately omit it. Clearing Database file(s) also restores the
  `Select instrument` placeholder.

## Data visualization

- **Parameter order is consistent from selection to plotting.** Temperature
  starts Select plot. The routine list is Temperature, Salinity, O₂, pH,
  Chlorophyll, Turbidity, PAR, CO₂ and Organic matter; Conductivity, Pressure,
  Density and Soundspeed remain together at the end under *Rarely used* and
  start unchecked. Scale settings follows the same order.
- **Fixed-scale defaults cover every value that a panel will draw.** Their 20%
  margin is a visualization choice independent from QC sensor limits. On the
  reference Seaguard file, a finite PAR maximum of 4,909.6079 µmol/m²/s
  therefore produces a suggested plot maximum near 5,892 even though the PAR
  sensor-range test ends at 5,000.
- **Trend controls are low-order and persistent.** Regression degree is a
  compact spin box limited to 1-5 (default 2); older saved values are
  normalized before use. The trend switch and degree persist immediately when
  edited, and scalar point markers keep the same three-pixel size with or
  without a trend line.

## Plot toolbar and Figure options

- **Figure options edits real lines, not point-only series.** Solid is listed
  first, line width resets to the original product value, and point markers no
  longer masquerade as lines whose dashed styles connect independent samples.
- **Applying a style preserves the live zoom.** Figure options is non-modal;
  untouched Min/Max fields no longer overwrite a wheel or toolbar zoom made
  while the window is open. Explicitly edited or reset bounds still apply.
- **Titles and legends match the figure structure.** Figure and plot titles
  persist across the parameters of one multi-axis figure, scale choices use
  capitalized display names, and the Legends tab appears only when the selected
  plot has an editable legend or key.
- **The coordinate readout reports only a real plotted glyph under the
  cursor.** Empty areas and ordinary line segments stay blank; simultaneous
  point values are named. PAR is shown in positional notation rounded to a
  whole unit, and Doppler heatmap cells and vector arrows again report their
  current values.

## Quality control settings

- **All three tabs follow the visualization variable order wherever a control
  exists.** Routine sensors precede Conductivity and Pressure; Density remains
  last in its applicable profile block. Soundspeed correctly has no
  independent QC control. Statistical-threshold parameter labels now end in a
  colon.

## Note

- **No archived product was rewritten.** The PAR scale explanation above was
  verified from the raw reference session and changes only visualization
  defaults. The pre-v13 Doppler/PAR requalification remains deferred.
