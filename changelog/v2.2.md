# QCS v2.2 — Result-affecting bug fixes, usability and reorganization

> **MINOR** release (v2.1 → v2.2) by its number — but several of the fixes below
> **change qualification results**, the UNESCO depth formula above all. Under the rule
> adopted from v3.0 onwards (any change to qualification results is a MAJOR bump) this
> would have been a major release; it predates that rule, and the number was never
> corrected because the tags and releases already point at it.
>
> Practical consequence: files qualified before v2.2 have wrong depths and cannot be
> compared with later ones without requalifying.

A broad revision: bug fixes that affected results, usability improvements and a
reorganization of the project.

## Reorganization
- Scripts moved into `sourceCode/`; run directly from the `.bat` shortcuts (no packaged
  executable required).
- Added `requirements.txt` and `QCS_SelfTest.py` (10 self-tests on synthetic data).

## Bug fixes
- **Depth:** the UNESCO pressure→depth formula used `lat/5.29578` instead of
  `lat/57.29578` (the degrees→radians conversion). Every depth computed from pressure was
  wrong.
- **Latitude:** no longer hardcoded (`17.5`) and now a field in the interface.
- **CSV export** was saving the file with an `.xlsx` extension.
- **pH × chlorophyll:** the (case-insensitive) search for the pH column also matched
  "Chloro**ph**yll" and erased chlorophyll data when removing bad/suspect data.
- **Flag deduplication** rewritten with `np.isin` (the previous logic failed with 2 or
  more repeated indices).
- **The outlier test** computed but never applied the suspect flag (3).
- **Output File Name** was ignored on export.
- **The sampling interval** gained sub-second precision (8 Hz spreadsheets caused a
  division by zero).
- **Records with no date/time** are discarded on reading (a truncated line broke the
  plots).
- Several interface freezes (rejecting a spike, closing a plot without selecting, a time
  window in days, and others).

## Improvements
- The test blocks in `QCS_Main` refactored into a single `test_sequence` (~400 fewer
  lines; it removes the risk of silently misaligning the flags).
- The main window stays open between qualifications (iterative RUN).
- User preferences persisted in `qcs_user_settings.json` (last folders and choices).
- Input validation with clear warnings; completion and error messages.
- Fixed, contrasting variable colours in every plot (`getParamColors`, centralized).
- The version centralized in `QCS_DataHandler.QCS_VERSION`.
