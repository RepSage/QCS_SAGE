# QCS v11.3 — The window fits the screen it is on

> **MINOR** release (v11.2.2 → v11.3): two usability features for small
> screens, born on the field notebook. No change to qualification results.

## The problem

On the field notebook's low display, the Data Qualification tab is taller
than the window: the bottom row of options — **Check variables** and **Light
cutoff** — slid out of view, and there was no scrollbar to reach it. The
Execution log, fixed at the bottom, made the useful area even shorter.

## The features

- **The qualification tab scrolls when it does not fit.** The tab content
  now lives in a scrollable container whose vertical scrollbar appears only
  when the window is too short for the content — on a large screen nothing
  changes visually. The mouse wheel scrolls it (and keeps being ignored when
  everything already fits).
- **Hide log / Show log.** A new button to the left of *Clear log* collapses
  the Execution log's text area, giving its vertical space to the tabs; the
  title bar with the buttons stays, messages keep accumulating while hidden,
  and *Show log* brings the text back — with everything it logged meanwhile.
  The choice is remembered across sessions (`log_hidden` in the user
  settings), so the field notebook can keep the log tucked away for good.
  Hiding the log is often enough by itself to make the whole tab fit, which
  also dismisses the scrollbar.

## Verification

- 16 live-GUI checks (real app shell, no mocks): scrollbar appears/hides with
  the window height, the Check variables row is reachable by scrolling on a
  short window, the toggle collapses and restores the text area in the right
  stacking order, the preference round-trips through the settings file.
- Full self-test suite: 51/51. `ruff`: clean. Qualification logic untouched.
