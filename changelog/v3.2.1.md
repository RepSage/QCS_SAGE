# QCS v3.2.1 — Fixes and a visual adjustment

> **PATCH** release (v3.2 → v3.2.1): bug fixes and a cosmetic adjustment, no new
> features and no change to qualification results.

## Fixes
- **"Select Profile Data" froze the interface:** the down/up profile selection called
  `plt.show(block=True)` inside the RUN button callback while Tkinter was already
  running — that created a nested matplotlib event loop which **froze the interface**
  (it looked hung and produced the spreadsheet only once the figure was closed).
  Replaced with the correct pattern: a non-blocking figure plus
  `window.wait_variable`, with close handling (closing the window keeps the whole
  dataset) and a clear instruction in the plot title.
- **FILTER SETTINGS panel layout:** removed a `rowconfigure(weight=1)` left over from an
  older layout which, with the taller visualization panel (the depth fields added in
  v3.2), opened a gap in the middle of the panel. Two orphan labels (tooltips on
  invisible widgets) were also fixed, and are now attached to the real labels.

## Visual adjustment
- **Visualization colours:** O₂ was being confused with salinity. Colours rotated:
  O₂ → blue, salinity → orange, conductivity → teal. All remain distinct, in every
  plot (time series, profiles and panels).
