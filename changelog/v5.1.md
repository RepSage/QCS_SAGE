# QCS v5.1 — Time-of-day standardized cross-site panels + replicate spread band

> **MINOR** release (v5.0 → v5.1), developed on branch `improvements-v5.1`.
> Visualization-only changes: no QC test, threshold or flag behavior is altered.
> Note: the version bump resets saved QC criteria to the (unchanged) defaults on
> first launch, per the version-gated settings rule.

## Cross-site panels standardized by time of day (B6)

When sites are sampled on **different days**, what matters for comparison is the
**time of day**. The two cross-site panels no longer use elapsed-time or
absolute-date X axes:

- **"Parameter across sites" (Panel 2)** and **"HOBO Light multi-site"** now plot
  against **hours since midnight of each site's own first sampled day**: x = 15
  is 15:00 of day 1 for every site, day 2 continues at 24-48 h, and so on. Sites
  sampled on different dates **overlay by clock time** while the deployment
  sequence is preserved.
- Ticks are labeled with the **clock hour** (00:00, 06:00, 12:00, ...) repeating
  identically day after day, with a light dashed line at each **day boundary**
  (multiples of 24 h). Tick steps are clock-aligned (1/2/3/6/12/24 h).
- The **X-axis time window** follows the same rule on these panels: its **day
  offset plus clock time** apply to each site's own days (e.g. a window from
  day-1 06:00 to day-2 12:00 selects that range of every site's own deployment).
  With a single site this reduces exactly to the absolute window. Panel 1 and
  the per-site HOBO panels keep absolute dates (they show one site at a time).
- The HOBO multi-site fouling **cutoff markers** are drawn at the corresponding
  anchored hour (the cutoff date stays in the legend label).

## HOBO combined replicates — spread band

- The **HOBO temperature panel** now shades the **between-replicate
  disagreement** when the file carries the `Temperature spread (degC)` column
  (combined-replicates output): a band of total width = spread (max - min),
  centered on the plotted mean, labeled "Replicate spread (max - min)" in the
  legend. Single-replicate files are unchanged (the column is empty).

## Nothing negative on physically positive variables

Every variable in this software is physically >= 0 (values <= 0 are discarded or
clamped at qualification), so the visualization now respects that floor:

- **Fixed-scale Min defaults never go below zero**: the 20% breathing room used
  to push variables that reach down to 0 into negative territory (e.g. PAR
  spanning 0-4500 got a -900 default). The Min default is floored at 0.
- **Tendency curves are floored at 0**: a polynomial fit through data that sits
  at zero (e.g. PAR at night) used to dip below zero. The fitted curve now
  follows the zero line wherever the polynomial goes negative and rejoins it
  where the fit returns above zero — in every panel (Panel 1 first axis and
  twins, Panel 2, and both profile axes of Panel 3, which previously hid the
  negative stretch as a gap).

## Qualification — Input type auto-detected

- Browsing to a raw data file now **auto-detects the instrument family** from
  the file header (`sniff_input_type`): a Seaguard/TSCP export opens with its
  device-description block; a HOBOware export has a "Plot Title" line and/or a
  Date-Time header with a light-intensity column (English or Portuguese). The
  Input type combobox is set accordingly (still editable); an unrecognized
  header keeps the current choice and logs an Info line. The user now only
  picks **TSCP Mooring / TSCP Profile**.

## Visualization — naming and small UX

- **Data type now uses the same names as the qualification screen**: "TSCP
  Mooring" and "TSCP Profile" (in this order), replacing "mooring"/"profile".
  For HOBO files the single (locked) option reads "Mooring".
- **"Parameter across sites" is unavailable when the database has a single
  site** (a cross-site comparison needs at least two); same rule for the HOBO
  "Light multi-site" panel.
- The "Reading:" file name is vertically aligned with the Data type combobox
  row.

## Qualification — usability round

- **Replicates follow the file selection**: for HOBO, Browse always
  multi-selects and the Replicates box just DISPLAYS how many files were
  picked (no more fixed 1-4 choice; the program says how many replicates
  there are). Picking several files that turn out to be a Seaguard export
  keeps only the first (with a warning).
- **Correct GMT-3 is unchecked (not only greyed out) for HOBO**; the last
  Seaguard choice is remembered and restored when switching back.
- **Light window review** gained **Done** and **Cancel** buttons at the end of
  its button row (same convention as the manual-cut panels): Enter = Done,
  Esc = Cancel (aborts the whole qualification, nothing written).

## Visualization — usability round

- **Data type defaults to "TSCP Mooring"** when a file is opened directly
  (no qualification handoff and no valid saved choice) instead of blank.
- **HOBO databases show "HOBO"** in the Data type box (was "Mooring"); the
  tooltip documents the three names.
- **All / None buttons** on both parameter groups (main and "Rarely used"),
  placed inside the group header rows so the 1:1 alignment with Scale
  settings is preserved (row heights are now measured generically on both
  sides).
- **Min/Max tooltips** in Scale settings explain the default rule: approved
  data (flags 1/2) of the current Site/Year selection ± 20% breathing room,
  Min floored at 0.
- **Year and Site filters default to ALL checked** (previously only the first)
  when nothing valid was restored for the database.
- **Every plot window opens in front of the main window** (brief topmost
  pulse in `style_plot_window` — qualification review/cut panels and all
  visualization panels; not permanently topmost).

## HOBO visualization — redesigned panels

The dedicated HOBO panels were replaced by TWO panels that behave like the
Seaguard family:

- **"Parameters at a site"**: the selected parameters (temperature and/or
  light) for one site in a single figure with twin axes, spanning **every
  selected year in one plot** (a deployment crossing the new year is no longer
  split into truncated per-year figures). Temperature keeps the suspect/bad
  highlights, the replicate-spread band and gains an optional **tendency line**
  (floored at 0). Light dropped the log scale: it is drawn as its **daily-peak
  envelope on a linear scale** (the same visual as the fouling review) with
  optional raw points and the fouling window shaded.
- **"Parameters across sites"**: one figure per selected parameter, all sites
  overlaid on the **time-of-day axis** (B6). Light uses the per-site daily-peak
  envelope with each site's fouling cutoff marked; temperature gains per-site
  tendency lines.
- The **parameter selection and Display options (trend lines / points / fixed
  scale) now apply to HOBO** exactly as they do to Seaguard.
- The profile panel, the T-S section and the Depth-axis fields are **removed**
  from the window for HOBO (they do not exist for a temp/light logger); the
  X-axis window labels read "(HOBO)".

## Step 1 / Step 2 usability

- **Recent** starts showing the most recently used selection (was blank).
- **Preview** is enabled only in "Build database from a folder" mode.
- **Output path** comes before **Output name** in Output settings.
- **Replicates** is a plain read-only count (no dropdown arrow — the value is
  program-determined from the file selection).
- "Filter by year:" is padded down to align with the (taller) parameters
  header.
- **Year and Site filters are no longer persisted**: every import starts with
  ALL years and sites checked (like the parameter selection).

## Fine-tuning round

- **Scale settings reflect the selection**: a checked parameter whose current
  Site/Year selection carries NO data now shows its Min/Max row greyed out
  (re-enabled automatically when the selection brings data back).
- **HOBO temperature dropped the suspect/bad "X" markers** (keeping or removing
  those values was already the operator's decision at qualification; the
  markers only cluttered the legend).
- The replicate band legend now reads **"Replicate disagreement (band height =
  max - min)"** and the band is slightly lighter — at each instant its vertical
  thickness is the difference between the highest and lowest replicate.
- The Min/Max **default-rule tooltips moved to the column headers** of Scale
  settings (one hover explains the whole column) instead of every entry.
- **"Sort by time" now comes before "Build database from a folder"** in Step 1.

## Replicate disagreement as per-sample bars + Recent follows the handoff

- The replicate-disagreement **shaded band was replaced by one vertical bar per
  sample** (bar length = max - min of the replicates at that instant, centered
  on the plotted mean). The continuous band interpolated the spread BETWEEN
  samples and, with HOBO's quantized temperature steps, read as translucent
  lines linking the dots. Legend: "Replicate disagreement (bar = max - min)".
- After a qualification, switching to Visualization now puts the just-qualified
  file **on top of the Recent list and shows it there** (Recent used to keep
  displaying the previous session's file while the fields already pointed to
  the new one).
