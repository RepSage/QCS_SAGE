# QCS v12.3 - the window stays alive while it qualifies

> **MINOR** release (v12.2.4 -> v12.3). No flag, threshold or test logic was
> touched, so no qualified value changes. Two DISPLAY defaults do change: the
> fixed-scale range now spans every plotted value, and every plot opens in a
> window the program builds itself.

## Data qualification

- **The qualification runs on a worker thread.** The window keeps repainting
  and answering while a file is being qualified, instead of freezing until the
  run ends. Measured on a DCPS session: 219 interface-thread timer ticks during
  a 15-second run, where a frozen window shows none. The pipeline itself was
  not rewritten for this - every point where it talks to the operator was
  already a hook, and the hooks now carry the call back to the interface
  thread and block the worker until it is answered.
- **A run can be canceled.** *Cancel* appears beside RUN while a qualification
  is in progress and stops it at the next step; the qualification unwinds
  through the same clean path a canceled manual cut always used.
- **A canceled run removes what it wrote.** The output folder of the
  interrupted file is deleted, so a mistaken run leaves nothing behind. A
  folder that ALREADY existed before the run - the usual case when
  re-qualifying over a previous product - is never deleted; the log says it was
  kept and may now hold files from the canceled run. In a batch, the files
  already finished keep their outputs.
- **Only Cancel is live while a run is in progress.** The input and output
  boxes, the settings button, the menus and the Visualization tab are disabled
  for the duration, and the wait cursor is gone: the window is responsive now
  and the cursor said the opposite.
- **A folder holding several sessions no longer kills the run.** Every
  `DataNNN.bin` of a folder is read as part of the same session, which is right
  for a session folder and wrong for a folder that merely holds binaries of
  different deployments: a DCPS session sitting beside a scalar one aborted the
  qualification with "unsupported layout variant", naming a file the operator
  never selected. A binary whose instrument differs from the selected one is
  now skipped, with a warning that says what to do.

## Plots (both tabs)

- **Every plot opens in a window the program builds**: the app icon, the
  plot's own title, and matplotlib's standard toolbar - the same header on a
  manual cut, a review and a produced panel. The visualization panels used to
  show a trimmed toolbar with a "Reset view" text button and no icon.
- **The home button works after a wheel zoom.** It returns to the view the
  window opened with. Matplotlib fills its navigation history only from its own
  pan/zoom buttons, and this program zooms with the mouse wheel, so the button
  had nothing to return to and did nothing.
- **A fixed scale covers every value that is plotted**, whatever its flag. It
  used to be computed from the approved values only: a HOBO series whose
  approved range was 25.9-30.1 degC got a scale of 25.07-30.88, and six SUSPECT
  points between 24.69 and 25.03 were drawn nowhere. The qualified sheet
  already reflects what the operator chose to remove, so what survives must
  fit on the scale. The same rule now applies to the Doppler speed colour
  scale, which was still built on the good cells alone.
- **A panel says when points fall outside its scale**: how many, of how many,
  and what to do about it. A hand-typed Min/Max can still crop a series - it
  is no longer silent.

## Data visualization

- **"Go to visualization" opens the panels of the run that just finished.** It
  goes to step 2 instead of stopping at step 1; the tab bar still opens step 1,
  as before. A batch hands over ALL its qualified files plus a database name,
  so step 2 shows one unified database of the whole run rather than its last
  file.

## Verification

- Self-test suite 54/54, ruff clean. The threading, the cancel, the cleanup and
  the scale change were measured on real sessions (a DCPS binary, a scalar
  Seaguard deployment and a qualified HOBO database), driving the real shell
  off-screen. The interactive reviews were exercised through the thread for the
  light window (by the owner, in the app) and the Depth review (by probe); the
  manual point cut and the replicate review were not.
