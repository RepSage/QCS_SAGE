# QCS v13.2.4 - direct feedback and a consistent release history

> **PATCH** release (v13.2.3 -> v13.2.4). Quality-control tests, thresholds,
> flag layouts, database rules and qualified values are unchanged. This release
> adds a direct issue-reporting shortcut and brings the complete GitHub release
> history into the project's current editorial format.

## New

- **Bugs & Suggestions opens a blank GitHub issue from the menu bar.** The
  top-level action sits beside Help in the released Qt shell and the retained
  Tk fallback. It opens the repository's unrestricted new-issue form so an
  operator can describe a problem or suggestion in their own words.
- **The user manual explains the reporting path.** The interface overview and
  troubleshooting section name the new action and the evidence that makes a
  report useful: QCS version, operation, observed result, Execution log and
  crash log where applicable.

## Note

- **All 46 pre-v13.2.4 GitHub release descriptions follow one structure.**
  Their titles, opening sentence, Fixed / New / Note / Verification / Install
  sections and bold claim-first bullets were reconciled against the versioned
  changelogs, using v11.6 as the editorial reference. Source tags and assets
  were not changed.
- **Three reconstructed releases keep their unusual chronological position.**
  GitHub sorts the Releases page by immutable creation time. v2.1, v2.0 and
  v1.0 were reconstructed on 2026-08-11, so they appear between v11.0 and
  v10.0. The edit endpoint cannot change either creation or publication time;
  deleting and recreating releases would discard their IDs, historical dates
  and download records, so the history was preserved.
- **QC and database semantics are unchanged.** No reader, test, threshold,
  flag, qualification pipeline, curated-corpus rule or visualization rule
  changed in this release.

## Verification

- **Release verification is completed before tagging.** The final suite, lint,
  interface probe, installer build and frozen launch results are recorded here
  only after they have run.

## Install

Download and run **QCS_Setup_v13.2.4.exe**. Installing over an existing copy
upgrades it in place and keeps saved folders and interface preferences.
