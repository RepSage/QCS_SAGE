# QCS v12.2 - the interface remembers again

> **MINOR** release (v12.1 -> v12.2). The QC rules and the default criteria are
> UNCHANGED: no flag, threshold or test logic was touched. As with every version
> change, saved quality criteria are reset to the program defaults on first run
> (file paths and interface choices are kept), and the program says so.

## Fixed

- **Nothing was kept between sessions.** Three separate causes, all of them
  introduced when the interface moved to Qt:
  - The two halves of the program each held their OWN copy of the settings, and
    each one rewrote the whole settings file: whichever half saved last put back
    what the other had just changed. A qualification setting could be undone by
    opening the visualization tab, and the other way round.
  - The window state was never saved: size, position, maximized state and the
    Execution log's visibility were lost on every close.
  - The form was only stored by a qualification that ran to the end, so a
    session that selected files and closed without running lost the selection.
- **The program is started as the user, never as the administrator the
  installer ran as** (both the finish-page button and the reopen after a
  one-click update). Windows blocks file drag-and-drop from Explorer into a
  program running with higher privileges, which is why dragging files stopped
  working right after installing, until the program was reopened from its
  shortcut.

## Data qualification

- The **CO2 line of the Selection summary** is shown only where CO2 data can be
  added - a Seaguard scalar run - and is hidden for HOBO files and for current
  profiler (Doppler) sessions.
- The **output folder of the visualization tab** is remembered, and its picker
  opens where the last one did instead of scanning the drive root.

## Notes for whoever maintains this

- `QCS_Main.store_form_prefs()` is now the single place that writes the form to
  the settings file; it is called both by a validated RUN and by the window's
  close handler. `QCS_Main.remember_data_dir()` is the single place that writes
  the last-used data folder, for both interfaces.
- A shell MUST alias the two preference dictionaries
  (`qm.USER_PREFS = dbv.USER_PREFS`) or the last save wins; the rule is in
  `CLAUDE.md`.
- The Qt window state lives under its own keys (`qt_win_geometry`,
  `qt_win_layout`), saved through `QMainWindow.saveGeometry`/`saveState`; the
  older tk keys are a different format and are left untouched.
