# QCS v14.0.1 - native Doppler corrections with the v14.0 display

> **Owner-approved PATCH** release (v14.0 -> v14.0.1). Doppler decoding,
> cell coordinates and native-status qualification change. The owner explicitly
> retained this work within v14.0.1 instead of the usual QC MAJOR bump.

## Fixed

- **DCPS records retain their native geometry and status.** Both vector widths
  validate field kinds, declared counts and payload bounds. Valid partial records
  remain explicit; malformed framing stops decoding. Configured centers and
  spacing, surface/instrument references, both cell states and DCPS-owned record
  metadata are retained instead of inferring them from scalar fields.
- **Native warnings no longer become GOOD or indiscriminately BAD.** Supported
  TD304-2024 warnings become SUSPECT and invalid solutions become BAD. A missing
  beam requires configured AutoBeam replacement. Missing/unmapped native quality
  cannot certify GOOD; an unreviewed manual position remains non-contributing.
  The generated flag legend explains these distinctions. Physical thresholds
  are unchanged.
- **Scalar profiles without finite depth still export their tables.** Vertical
  and depth-colored T-S panels are skipped with an explicit message. Empty
  Site/Year selections no longer borrow extrema from unselected scalar data.
- **Reused Doppler destinations remove obsolete generated panels.** Earlier
  root and group SVGs are cleared without removing unrelated files; the corpus
  index also recognizes retained historical panel subfolders.

## New

- **Working-depth context is green in manual review.** Recovery/handling remains
  red, with both lines dashed and their legend keys using the same colors.
- **Other families use line-only legend keys.** Plotted observation markers
  remain unchanged; Doppler retains the v14.0 legend appearance.

## Note

- **Doppler presentation remains the literal v14.0 behavior.** Surface cells and
  configured columns share the same panel set; saved depth bounds, legends and
  fixed-scale behavior follow that tag. Coincident time/depth rows may be averaged,
  including arithmetic direction averages, and different coordinate references
  can share one axis. These are display aggregates, not individual native cells.
  Reader, geometry and QC corrections remain in the qualified tables.
- **Requalify older Doppler products to receive the corrections.** Restoring a
  plot style does not restore old measurements. Seaguard/HOBO timebase rules and
  physical thresholds are unchanged. DCPS checksum validation and a general
  decoder for refused legacy HOBO event layouts are not added by this release.
- **Archive operations have their own record.** Requalification, clock repairs
  and source decisions belong in `sourceCode/batch/CORPUS_LOG.md`. This release
  does not rewrite the archive's existing SVGs.
