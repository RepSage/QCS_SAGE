# QCS v11.4 — Raw .hobo files qualify directly; units come from the source

> **MINOR** release (v11.3 → v11.4): the HOBO Pendant's raw `.hobo` binary
> becomes a first-class input (experimental), pressure/conductivity units are
> read from the file instead of asked of the user, and the window remembers
> its state. Qualification rules unchanged.

## Raw `.hobo` reading (experimental)

The `.hobo` binary format (HOBO Pendant Temp/Light, UA-002 family) was
reverse-engineered from this archive's 200+ file/export pairs and is decoded
directly — select the `.hobo` like any data file; no HOBOware export needed.

- Record = 18 bits ([light 8][temp 10]); the current deployment sits at the
  front of the logger memory, found by scanning bit alignments against the
  calibration tables; older deployments left in memory are ignored.
- **Calibration tables** (`QCS_HoboCal.py`): temperature 10-bit code → °C,
  derived from 97 corpus files whose decode matches their exports ≥ 99.9%
  exactly — universal across loggers (zero conflicts), monotone, ~0.1 °C
  steps. Light 8-bit companded code → lux (linear to code 128, then
  mantissa/exponent steps ×8/16/32...; lux = raw × 10.7639).
- Timestamps: launch (header) + 1 s + one interval per stored sample, in
  GMT-03 (a logger launched on another UTC offset is shifted, with a
  warning). The reading HOBOware shows at launch time was taken in air
  during configuration and is not stored in the binary.
- **Blind validation** (no export in sight, then compared to the export):
  42 corpus files reproduce their HOBOware export at 100.0% exactly in both
  channels; the current-generation families all pass. Files from older
  HOBOware generations that do not fit the deciphered layout — or whose
  decoded light "glows in the dark" (the tell of a wrong decode) — are
  REFUSED with a clear message instead of guessed.

## Units are read from the source (Units section removed)

All 255 Seaguard `.bin` sessions in the raw archive declare their units in
the template (`Pressure[kPa]`, `Conductivity[mS/cm]` — no exception), and
AADI text exports carry the same `Descr[Unit]` headers. The reader now
detects the unit there and converts to dbar / mS/cm automatically; the
Pressure/Conductivity dropdowns are gone. A text export whose
pressure/conductivity column names no unit is refused with a clear message —
the old silent default (kPa) could corrupt a conversion without a trace.

## Window and layout

- The window remembers maximized/normal state and geometry across sessions.
- Site code moved above Data filtering in Output settings.

## Verification

- Suite grown to 52 tests (new: synthetic `.hobo` spec round-trip with
  timebase and light-lag checks + refusal of a non-conforming stream; unit
  auto-detection with refusal of unit-less exports) — 52/52, ruff clean.
- Corpus-wide blind validation of the reader against 209 file/export pairs.
