# v14.1.1 - a readable startup splash

The startup splash added in v14.1.0 becomes a white card with a readable
message; QC rules unchanged (PATCH: v14.1.0 -> v14.1.1).

## Fixed

- **The startup splash is a white card with a readable message.** v14.1.0
  wrote a tiny 'Starting QCS...' over the icon, and the icon's transparent
  corners showed whatever was behind it. The icon now sits in a white border,
  with 'QCS initializing...' in bold 18 pt on the white band below it. The
  text uses the system UI font (Segoe UI), the font of the whole program. A
  hairline grey outline keeps the card visible over a white window, and the
  card is drawn at the screen's scaling, so it stays sharp on scaled displays.
  Owner design: the border of one preview, with the bold text of another.

## Note

`QCS_INSTANCE_KEY` (an environment variable) overrides the single-instance
key. It exists only for release smoke tests: a test copy must never talk to
the operator's running QCS. During this work, a check that used the real key
brought the operator's open window to the front and exited.

## Verification

- **Self-test suite: 93/93; Ruff clean.**
- **Single instance passed offscreen, 5 of 5.** The real shell booted through
  the new splash, on a test key, with the splash closed when the main window
  appeared and operator preferences untouched.
- **The splash itself was rendered by the real function** with the Windows
  platform and the system font: 264 x 300 logical pixels, Segoe UI bold.

## Install

Download and run `QCS_Setup_v14.1.1.exe` from the GitHub release. Installing
over an existing copy upgrades it in place and keeps saved folders and
interface preferences; the version gate applies the current QC defaults on the
first launch.
