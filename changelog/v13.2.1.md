# QCS v13.2.1 - multi-deployment visualization fixes

> **PATCH** release (v13.2 -> v13.2.1). Quality-control tests, thresholds,
> flag layouts, qualified values and the archived corpus are unchanged. This
> release makes broad curated HOBO selections source-aware and keeps their
> filter and panel state explicit.

## Fixed

- **HOBO campaigns no longer become one historical series.** At-site and
  across-site panels use the preserved `Source file` provenance to keep daily
  light peaks and temperature tendencies separate for every deployment.
- **Light lines no longer cross unsampled intervals.** Daily resampling retains
  empty days as NaN breaks. A gap inside an already-BAD deployment no longer
  creates another vertical fouling marker.
- **Recorded BAD light has an unambiguous visual.** At-site panels shade the
  absolute `Flag_lux == 4` interval without a red cutoff line; elapsed-time
  comparisons dot and fade each deployment's BAD segment instead of unioning
  several campaigns into a misleading background span.
- **Tendencies use real elapsed time.** Polynomial fits use normalized datetime
  intervals, average duplicate timestamps for the fit and omit missing values;
  unequal sampling gaps are no longer treated as adjacent sample positions.
- **Broad HOBO selections open once.** Every at-site and across-site figure is
  collected into one paged window with Previous, Next and direct panel
  selection. Site labels appear once per comparison, plus one BAD-style key.
- **Curated filter state stays visible.** Incompatible site, calendar-year and
  instrument values remain in their lists but turn gray and are unchecked.
  Broadening another facet never silently restores an invisible selection.

## Note

- **QC and DATABASE light rules are unchanged.** The current HOBO corpus keeps
  its recorded fixed 60-day light windows; v13.2.1 only changes how qualified
  products are visualized.
- **Standalone products retain their behavior.** A table without `Source file`
  provenance is treated as one deployment; curated workbooks continue to use
  the original source filenames written by `build_database()`.

## Verification

- **The QCS self-test suite passed 67/67.** New regressions cover real-time
  tendency fitting, retained daily gaps, source-aware fouling spans,
  deployment-relative alignment, BAD display and paged figure collection.
- **The full current corpus retained the expected rows.** Direct discovery and
  read-only build selected 282/282 contributing products: 644,411 source rows
  became 644,321 unified rows after 90 exact duplicates were removed. The
  existing 10,654 non-identical Site+Datetime overlaps remained present with
  the engine's warning. Instrument rows were Seaguard 163,152, Doppler 129,382
  and HOBO 351,787.
- **All 116 current HOBO products passed the broad-selection replay.** Sixteen
  figures were collected; across-site axes ended at 736.2 days for temperature
  and 691.6 days for light, with zero vertical BAD markers, zero background BAD
  spans, zero finite line bridges across missing days and 15 light-legend items.
- **Off-screen Qt probes exercised the real handoff.** A 6,786-row curated
  workbook with two sites and three source deployments opened directly on
  Visualization Step 2 and produced exactly four titled figures through one
  paged call. A separate facet probe proved incompatible values remain visible,
  disabled and unchecked.
- **The frozen release artifacts passed their build and launch checks.** The
  301,421,676-byte PyInstaller bundle rendered the v13.2.1 application and
  exited without a crash log. Inno Setup 6.7.3 produced the 81,726,912-byte
  `QCS_Setup_v13.2.1.exe` installer with SHA-256
  `BD357B07241CA92C05BEA7395DC15C72230E754D6D8BAEC41EDFAC9CFE3E5AA2`.

## Install

Download and run **QCS_Setup_v13.2.1.exe**. Installing over an existing copy
upgrades it in place; installed copies of v11.2+ will offer this update on
startup. The default remains the existing all-users location under Program
Files (x86), with the per-user option available in the wizard.
