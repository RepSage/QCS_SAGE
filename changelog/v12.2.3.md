# QCS v12.2.3 - only the variables the data has, written the way they are read

> **PATCH** release (v12.2.2 -> v12.2.3). The QC rules and the default criteria
> are UNCHANGED: no flag, threshold or test logic was touched.

## Data visualization

- **The parameter lists show only what the database carries.** A column that is
  present but empty - CO&#8322; when no CO&#8322; logger file was merged into
  the qualification, an optical group the cast did not have - used to take a
  row in *Filter by parameter* and another in *Scale settings*, offering a
  variable that could never be plotted. Both lists now skip it, and the *Rarely
  used* heading only appears if one of those variables survives.
- **Units are written the way they are written on paper**: °C, µM, µmol/m²/s,
  µg/L, kg/m³, and the formulas carry their subscripts (CO₂, O₂). This is the
  label only - the column keeps its own name in the qualified sheet, which is
  what the plots, the flag columns and the settings are built from. The same
  labels are now used in both interfaces; the Qt lists had been showing the raw
  column names, including the "level" filler the tk step 2 already dropped.
- **Step 1 fits its content.** The Input and Output settings boxes were
  stretched to the full height of the page, which pushed **Next >** to the
  bottom edge; the boxes now take the height they need and the button sits
  right under them.

## Documentation

- The **user manual** carries the revision made after the v12.2.2 installer was
  built: the release history is out of it (that is what this folder is for),
  and what those lists were the only record of moved into the sections it
  belongs to - the Selection summary, the Recent box, what the program
  remembers between sessions, and the update flow with its finish-page
  checkbox.
