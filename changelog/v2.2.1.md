# QCS v2.2.1 — Visualization usability, language standardization and cleanup

> **PATCH** release (v2.2 → v2.2.1): usability, language and housekeeping only, with no
> change to qualification results.

A usability refinement of the data visualization, language standardization and project
cleanup.

## Visualization (QCS_DatabaseView / QCS_DataView)
- **"< Change Database" button:** returns to the selection window so another qualified
  file can be opened without closing the program. The tool now runs in a cycle
  (select → load → visualize → go back).
- **Years as checkboxes:** the year text field was replaced by checkboxes listing the
  years actually present in the spreadsheet (detected automatically). More than one year
  can be ticked — the panels are generated for each. A clear error if no year is ticked.
- **X-axis time window (mooring):** "X-Axis Start/End" fields fix the period of the time
  axis (format `DD/MM/YYYY HH:MM`), standardizing the scale across plots even where there
  is no data. Greyed out when the type is "profile".
- **Available period:** a label under the X-Axis fields shows the date range covered by
  the loaded spreadsheet, so the file need not be opened to check.
- **Persistence:** panels, sites, variables, min/max scales, ticked years and the time
  window are saved between iterations and sessions.
- Robustness: loading errors no longer close the program (they return to the selection);
  a warning when "Generate Panels" is clicked without having saved the settings.

## Plots
- **O₂ and CO₂** displayed with a subscript "2" (the correct chemical notation) in every
  series, profile and panel. This applies to the display only; the column names in the
  spreadsheets stay ASCII.

## Language and interface
- The whole interface, messages, logs and `.bat` shortcuts standardized in English.
- The terminal closes automatically when the program exits; it stays open only on error.

## Project cleanup
- Removed the window-icon lookup (and the dead `resource_path` function).
- Removed: the `.ico` icons, the PyInstaller `.spec` files, `environment.yml`,
  `Python.gitignore`, the `backup/` folder and the empty `Executables/` folder.
- Changelogs reorganized into the `changelog/` folder, one file per version.
