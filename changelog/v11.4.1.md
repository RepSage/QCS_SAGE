# QCS v11.4.1 — The .hobo file actually reaches the reader

> **PATCH** release (v11.4 → v11.4.1): one fix. No change to qualification
> results.

## The bug

v11.4 shipped direct `.hobo` reading, but the input validation in
`collect_input_settings` — a gate that predates the feature and checks the
file extension before anything is read — still only accepted `.csv`, `.xlsx`
and `.bin`. Selecting a `.hobo` and clicking RUN answered
*"Unsupported file format"* and the new reader was never reached. Found by
the owner on the first real attempt, minutes after the release.

## The fix

- The extension gate accepts `.hobo`, and its message now lists it.
- The Data file tooltip lists the format too.

The reader itself was unaffected (its corpus validation ran at the data
layer, below the GUI gate — which is exactly why the gate slipped through).
