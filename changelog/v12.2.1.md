# QCS v12.2.1 - the update asks before reopening; interface round

> **PATCH** release (v12.2 -> v12.2.1). The QC rules and the default criteria
> are UNCHANGED: no flag, threshold or test logic was touched.

## Updating

- **The update now runs the installer's wizard instead of installing
  silently**, and its last page offers **"Launch QCS after installation"**,
  ticked by default. A silent install has no finish page, so the only way back
  into the program was an automatic relaunch - and that relaunch did not happen
  on the owner's machine, twice in a row, with no evidence of why. Reopening is
  now something the operator sees and controls.
- The installer is run with `/LOG`, so the next report of a failed update comes
  with the installer's own account of it (`%TEMP%\QCS_update_install.log`).
- **The installer no longer ships the build machine's settings file.** The
  build recipe smoke-tests the frozen app inside the payload folder, and since
  v12.2 the app writes its preferences when it closes - so v12.2's installer
  carried the tester's `qcs_user_settings.json`. Harmless on a Program Files
  install, where the app keeps its settings in `%APPDATA%`, but a "just for me"
  install would have started with someone else's file paths.

## Data qualification

- **The Selection summary describes a Seaguard file that was copied out of the
  archive.** Serial, logging start and sampling interval used to come only from
  the session FOLDER names, so a lone `Data000.bin` - the usual way a file
  travels - showed three dashes. They are now read from the file's own header
  when the folder cannot supply them, at the same cost as before (measured
  0.01 s). A current profiler (DCPS) session also reports its interval now: the
  instrument declares it in the header, and that needs no decoding.

## Interface

- The **reset arrows** in Parameters and Factors per variable are drawn by the
  program instead of being typed as a character, so they are sharp at any
  screen scale and follow the light/dark theme. The shape is the one the owner
  chose from a sheet of candidates: two opposed arcs, each ending in a head
  whose tip and base both sit on the circle, so the head is centred on the
  curve rather than leaning off the tangent. They are drawn at 20 px because a
  pair of arcs needs the room - at 16 px each head is about three pixels and
  stops reading as an arrow.
- The **tooltips of the Quality control tests** no longer open with an empty
  strip on their left: the checkboxes were indented with a stylesheet rule,
  which Qt also applies to the widget's own tooltip (measured: 18 px wider than
  the same tooltip on an unstyled checkbox). The indent is now done by the
  layout.
- The window opened from **Quality control settings** is called that
  everywhere - the button and the File menu used to say "Parameter settings"
  while the window itself said "Quality control settings".
- The status bar's **criteria: CUSTOM** indicator is no longer clipped at both
  ends. It was sized from the widget's size hint, which stops growing once a
  fixed width has been applied; it is now measured from the text itself, for
  the wider of the two wordings, so it also never changes width when it
  switches.
