# QCS v13.2.3 - curated interactions and HOBO light clarity

> **PATCH** release (v13.2.2 -> v13.2.3). Quality-control tests, thresholds,
> flag layouts and qualified-value rules are unchanged. This release makes
> curated selection and progress more explicit and aligns HOBO light controls
> with the series that the plots actually draw.

## Fixed

- **Curated Selection rows toggle from their full width.** Clicking anywhere
  on an enabled Site, Year or Instrument row now checks or unchecks it. A
  direct indicator click still toggles exactly once, and incompatible disabled
  rows remain inert.
- **Curated Build progress begins at a visible, truthful boundary.** The bar
  starts at `Stage 0/N Preparing`, spells out `Stage` instead of the opaque
  `S`, and then counts selection, each selected instrument family and final
  workbook completion. Fast stages may advance between redraws without any
  artificial delay or omitted work.
- **HOBO luminosity no longer resembles a second dotted series.** Dense raw
  light points, dominated by nighttime low values, are no longer overlaid.
  The plotted light product remains the solid, marked daily-peak line for each
  source deployment, with qualified BAD light removed before resampling.
- **HOBO light-only controls reflect the available plot layers.** Tendency
  lines, regression degree, raw data points and replicate-disagreement bars
  are cleared and disabled when Luminosity is the only selected parameter.
  Selecting Temperature enables the applicable controls again, while Fixed
  scale remains available throughout.

## Note

- **DATABASE and QC semantics are unchanged.** The qualified corpus was not
  rewritten. This PATCH changes only selection interaction, progress wording
  and visualization layers/controls.
- **The neutral plot grid remains separate from light data.** Faint neutral
  grid lines only align values with axis ticks; the removed colored band was
  the optional raw-light point layer, not a tendency or fouling threshold.

## Verification

- **The QCS self-test suite passed 71/71.** Full-tree ruff, compileall, the
  HTML-manual parser and `git diff --check` were clean.
- **Targeted interaction and plotting probes passed.** Off-screen Qt checks
  covered row-body, indicator and disabled-row clicks plus `Stage 0/N`
  progress. A real curated HOBO workbook covered the tendency, data-point and
  fixed-scale control cycle; direct availability assertions covered
  disagreement bars. Both HOBO luminosity layouts contain only their
  source-aware daily-peak data lines.
- **The release artifact passed a clean frozen smoke.** PyInstaller 6.22.2
  produced a 301,444,534-byte onedir bundle; the complete main window rendered
  with exit code 0 and no crash log or bundled preferences. Inno Setup 6.7.3
  produced `QCS_Setup_v13.2.3.exe` (81,746,628 bytes; SHA-256
  `145E33271FC0A0BE24F763B282D04621F0E25B30EABDE8DC8FF0032116B51833`).

## Install

Download and run **QCS_Setup_v13.2.3.exe**. Installing over an existing copy
upgrades it in place; installed copies of v11.2+ will offer this update on
startup. The default remains the existing all-users location under Program
Files (x86), with the per-user option available in the wizard.
