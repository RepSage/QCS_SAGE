# QCS v3.1.1 — Correção

> Versão de **CORREÇÃO** (v3.1 → v3.1.1): conserto de bug, sem novas funcionalidades.

## Correção
- **Qualificação de perfil quebrava** com o erro *"cannot access local variable 'exceptions'
  where it is not associated with a value"*. Regressão introduzida na v3.1: ao mover o
  tratamento de "≤ 0" para `clean_below_zero`, a definição da lista `exceptions` foi
  removida, mas um uso dela permaneceu no trecho que remove dados rasos (profundidade
  < 0,5 m) de **perfis**. Afetava todas as qualificações de perfil (fundeio não passava
  por esse trecho). A definição de `exceptions` foi restaurada antes do uso.
