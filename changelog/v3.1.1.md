# QCS v3.1.1 — Bug fix

> **PATCH** release (v3.1 → v3.1.1): a bug fix, no new features.

## Fix
- **Profile qualification was crashing** with *"cannot access local variable 'exceptions'
  where it is not associated with a value"*. A regression introduced in v3.1: when the
  "≤ 0" handling was moved into `clean_below_zero`, the definition of the `exceptions`
  list was removed but one use of it remained, in the block that drops shallow data
  (depth < 0.5 m) from **profiles**. It affected every profile qualification (moorings
  did not go through that block). The definition of `exceptions` was restored before
  its use.
