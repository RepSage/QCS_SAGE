# v14.0.2 - Doppler current panels and Curated collection types

Display and workflow refinements from the RH30 review; QC rules unchanged
(PATCH: v14.0.1 -> v14.0.2).

## Fixed

- **Doppler panels use one consistent display velocity solution.** Speed,
  direction, arrows and U/V derive from the native horizontal speed/direction
  pair. AutoBeam polar fields can differ from named native North/East fields;
  both original solutions remain intact in the qualified table.
- **Surface and column cells stay together with stable identities.** Equal-height
  rows identify each source/column/cell/reference instead of suggesting layer
  thickness. Time bins retain internal gaps. Outer limits fit eligible current,
  removing large empty/BAD tails without deleting records or changing QC.
  Entirely ineligible selections produce an explicit message, not empty figures.
- **Direction and units are explicit.** Magnetic/true/unknown north labels use
  native metadata or exact adjacent provenance; labels never apply a correction.
  The compass W aligns with the upper color bar. Configured cell axes carry
  `(m)` in their title and use numeric ticks.
- **Curated scalar profiles retain their collection identity.** Catalog,
  workbook and visualization handoff agree on the exact collection sheet.
  Saved preferences cannot turn a proven Profile into Mooring. Legacy mixed or
  unknown scalar sheets offer an explicit choice and log excluded collections.
  Seaguard tables with both salinity and luminosity remain Seaguard.
- **Loading feedback starts before workbook inspection.** Curated handoff and
  panel generation use the window-local animated Windows blue cursor, with
  restoration on completion, nested calls and exceptions. Dialogs stay interactive.
  Nine Doppler settings/threshold tooltips follow the shared interface standard.

## New

- **Native, 15-minute and 30-minute current views.** Temporal means average
  consistent U/V components, then derive magnitude and direction; direction
  degrees are never averaged arithmetically. GOOD + SUSPECT and GOOD-only
  selections, linear or square-root contrast, coverage counts and QC reasons
  are available. Linear is the default; square root changes color contrast only.
- **Quality/coverage panels and experimental temporal diagnostics.** Editable
  spike, rate and flat-line previews aid inspection without overwriting the
  official five-position flags. Threshold calibration remains unfinished.
- **Four Curated categories.** Seaguard (Mooring), Seaguard (Profile),
  Seaguard (Doppler) and HOBO occupy separate workbook sheets. The canonical
  unifier still runs once per measurement layout; no competing merge engine
  was introduced. Conflicting evidence is refused; unknown types stay explicit.
- **Current figure footers are customizable.** Customize -> select a plot ->
  Legends -> Figure footer supports editing, clearing and reset. Figure export
  preserves the text; generating new panels restores the standard description.

## Note

Official qualification tests, thresholds and pipeline are unchanged. The earlier
owner-approved QC exception for v14.0.1 is not used here. Native measurement
fields and archived tables are preserved. Seaguard/HOBO timebase rules are
unchanged. Publication does not regenerate archived SVGs.

The RH30 2025 review found that width enlargement alone did not help. Display
consistency was more consequential: 1,325 of 6,557 eligible rows used a polar
solution differing from named N/E fields, all already SUSPECT. The final default
view retains all 6,557 eligible rows and 16 cells, including Surface; its outer
15-minute bins span April 1 11:15 through April 3 08:00 GMT-3. Equal-height rows
identify configured cells, not sampled layer thickness. Assessment evidence:
`diagnostics/rh30_2025_visual_assessment_20260909/REPORT.md`.
