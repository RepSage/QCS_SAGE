# QCS v11.6.1 — Every tooltip rewritten to one editorial standard

> **PATCH** release (v11.6 → v11.6.1). QC rules unchanged; only help text,
> spelling and the user manual. Groundwork for the v12.0 interface port:
> the port starts from tooltips already worth carrying over.

## Tooltips: one voice across the whole program

All ~150 tooltips (Qualification tab, Settings window — Quality Tests,
Parameters, Factors per Variable — and the Visualization tab) were rewritten
to a single documented standard (`QCS_Main.py`, above `TOOLTIPS`):

- Instrument names exactly as the interface shows them: **Seaguard, HOBO,
  DCPS, TSCP** (the stray `SeaGuard` spellings are gone, also from log
  messages and the manual).
- First line states what the control does or means, directly — no
  "Allows...", no "Check if...".
- Flags by name and code: **BAD (4), SUSPECT (3), DISMISSED (5)** — every
  test tooltip now says which flag a failure produces, which the old texts
  omitted.
- Scope prefixes where a control applies to one family: "Seaguard only:",
  "HOBO only:", "Profiles only:".
- At most ~4 short lines.

The ~90 per-variable range/test entries are now built from the variable
tables instead of hand-written near-duplicates, so they cannot drift apart
again. A coverage check against the old dictionaries confirmed the exact
same key sets (22 + 54 + 3 + 42; no tooltip lost).

## New tooltips

- The Execution log's **Hide log** and **Clear log** buttons.
- Stray hand-written tooltips (Replicates box, CO2 remove button, database
  Preview button, recent-selections list) aligned to the same standard.

## User manual caught up

The manual still said "For version v11.4.2" — the v11.5 and v11.6 releases
skipped it. It now carries: the version stamp, drag-and-drop, the
`Data file(s)` label, the empty-spread rule for single-covered rows
(v11.5), `Temperature series.svg` and the intentionally empty `Flag`
column of combined sheets (v11.6).
