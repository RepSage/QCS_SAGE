# QCS v13.3.0 - feedback without a GitHub account

> **MINOR** release (v13.2.4 -> v13.3.0). Quality-control tests, thresholds,
> flag layouts, database rules and qualified values are unchanged. This release
> replaces the external GitHub issue page with an internal support-email form.

## Fixed

- **Reporting a problem no longer requires a GitHub account.** Bugs &
  Suggestions now stays inside QCS while the operator writes the report,
  instead of opening GitHub's sign-in-dependent issue form.

## New

- **The internal form collects a title, description and optional name.** Title
  and description are validated before either output is prepared, and the
  report automatically identifies the running QCS version.
- **Open email prepares a complete message to the support contact.** Windows
  opens the operator's default email application with the recipient, subject
  and report body filled in. The operator can review and edit the message
  before selecting Send.
- **Copy report provides a service-independent fallback.** The same complete
  text can be copied to the clipboard for webmail or another communication
  channel when the computer has no default email application.

## Note

- **QCS does not send email or create a GitHub issue automatically.** No
  GitHub token, hosted backend or stored credential is needed. The operator
  explicitly sends the prepared message; the repository owner can then
  register it on GitHub when appropriate.
- **QC and database semantics are unchanged.** No reader, test, threshold,
  flag, qualification pipeline, curated-corpus rule or visualization rule
  changed in this release.

## Verification

- **The QCS self-test suite passed 72/72.** The added checks cover required
  fields, exact email encoding, the injected no-launch test path and a clear
  failure when Windows has no email handler. Full-tree ruff, compileall, the
  HTML-manual parser and `git diff --check` were clean.
- **Both interface implementations passed direct probes.** The Qt form and
  retained Tk fallback copied the versioned report, called only the injected
  email launcher, confirmed that the operator must select Send, and closed
  cleanly. The Qt form also passed visual inspection at its native size.
- **The release artifact passed a clean frozen smoke.** PyInstaller 6.22.2
  produced a 301,450,720-byte onedir bundle containing 2,334 files; the new
  feedback module is present in its module table. The executable rendered the
  complete v13.3.0 shell with exit code 0 and no crash log or bundled
  preferences. Inno Setup 6.7.3 produced `QCS_Setup_v13.3.0.exe` (81,754,083
  bytes; SHA-256
  `CE06BFEB00DA0B20F40071444DF9D2B22DB05DBBD6EEB08149DB2F573F9DA4C0`).

## Install

After publication, download and run **QCS_Setup_v13.3.0.exe**. Installing over
an existing copy upgrades it in place and keeps saved folders and interface
preferences.
