# QCS v13.2.2 - calendar-domain and plot polish

> **PATCH** release (v13.2.1 -> v13.2.2). Quality-control tests, thresholds,
> flag layouts and qualified-value rules are unchanged. This release makes
> multi-deployment scalar plots calendar-explicit, omits recorded BAD light
> from HOBO panels and completes a focused interface-polish round.

## Fixed

- **Multi-deployment scalar panels retain absolute calendar time.** HOBO and
  multi-deployment Seaguard mooring panels open on one continuous domain from
  1 January of the earliest checked year through 1 January after the latest.
  Only selected-year data are drawn, and the optional Time window remains a
  finer crop. Doppler, profiles and single-deployment Seaguard panels keep
  their established behavior.
- **Source deployments stay separate and identifiable.** Temperature and
  parameter tendencies, pressure series and daily light peaks are calculated
  per source product. Figure options names these lines by site, role and source
  instead of exposing Matplotlib identifiers such as `_child3`.
- **HOBO luminosity panels omit recorded BAD light.** Samples with
  `Flag_lux == 4` are excluded before raw points and daily peaks are drawn;
  the former BAD shading, dotted segments and legend key are gone.
- **Plot navigation permits a useful zoom out.** Wheel and toolbar zoom can
  reach 100 times the opening span, while Home remains the sole control that
  restores the opening view.
- **Figure resets no longer alter the live view or invent markers.** Reset
  values restores figure styles and text without changing zoom or pan. Exact
  marker aliases are retained, so a marker-free line remains marker-free and
  the original 1.5 line width renders correctly.
- **Curated progress starts and finishes at the real boundaries.** Load
  catalog stays empty at `Calculating...` until the product count is known,
  then advances from `Catalog 0/N`. Build clears prior state before display
  and stays below 100% until the atomic workbook write has completed.
- **Busy workflow tabs communicate their locked state.** Qualification and
  curated jobs dim and disable all three workflow tabs, including the active
  one, while leaving its visible page and Cancel control enabled.

## New

- **Legend keys have independent visual controls.** Line legends expose
  symbol, symbol color and symbol size without changing plotted observations.
  Circle is the neutral default, `(None)` stays first and Dot is explicit.
- **Plot styling controls are clearer.** Lines use a full Color swatch while
  preserving opacity, and datetime axes expose an editable Axis label above
  the available interval.
- **The main shell follows the native Figure options treatment.** Workflow
  tabs use the Qt/Fusion appearance, reserve enough width for bold active
  labels and sit below a cleaner divider-free menu header. The criteria text
  is anchored at the left of the status bar and progress at the far right.

## Note

- **DATABASE and QC semantics are unchanged.** The qualified corpus was not
  rewritten. Current HOBO products retain their recorded fixed 60-day light
  windows; this PATCH changes only whether `Flag_lux == 4` readings are shown
  in luminosity panels.
- **Known qualified BAD outliers remain available.** Automatic Y scaling can
  still be stretched by qualified values marked flag 4. Changing that policy
  requires a separate owner decision and is not part of this release.

## Verification

- **The QCS self-test suite passed 68/68.** Full-tree ruff, compileall, the
  HTML-manual parser and `git diff --check` were clean.
- **Synthetic and full-corpus multi-deployment replays passed.** A four-source
  Seaguard selection used the exact 2024-01-01 to 2027-01-01 domain. All 48
  current Seaguard mooring products built 129,780 rows and retained the 2023
  data gap; every parameter had 48 named source lines.
- **All 115 current HOBO products passed the revised light replay.** The
  read-only build retained 348,183 rows after 90 exact duplicates were removed.
  PAB3 and across-site light panels produced 17 and 113 deployment lines with
  zero BAD-named lines, dotted BAD segments or BAD-window patches. A targeted
  PAB3 2026 render kept 1,440 GOOD readings and 61 daily peaks while excluding
  all 2,829 BAD readings.
- **Off-screen Qt probes covered the interaction fixes.** They verified the
  calendar domains, semantic line names, progress boundaries, reset behavior,
  legend controls, datetime Axis label, native tabs, unclipped bold labels,
  divider-free header, status-bar spacing and dimmed busy tabs with Cancel
  still enabled.
- **The release artifact passed a clean frozen smoke.** PyInstaller 6.22.2
  produced a 301,440,432-byte onedir bundle. Its complete main window rendered
  to a screenshot, returned exit code 0 and wrote no crash log. Inno Setup
  6.7.3 produced `QCS_Setup_v13.2.2.exe` (81,745,104 bytes; SHA-256
  `84C0B392E1847BACF9F5C4AD88AB39AAE2B365AC29F4A7C9A8AC0739FF6DBDBD`).

## Install

Download and run **QCS_Setup_v13.2.2.exe**. Installing over an existing copy
upgrades it in place; installed copies of v11.2+ will offer this update on
startup. The default remains the existing all-users location under Program
Files (x86), with the per-user option available in the wizard.
